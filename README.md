#v5 csharp

Приватный сервер Brawl Stars на версии v5, написанный на C# (.NET 8).

Что реализовано

Лобби

логин, ящики и всякая шняга, прокачка бойцов, скины, лидерборды
клубы и клубный чат, румы

Бои

матчмейкинг по локациям, если людей не хватило, добираются боты
карты берутся из maps.csv: стены, кусты, ящики, точки появления
режимы: награда, захват кристаллов, броубол, ограбление, выживание (соло и пара), схватка с боссом
оружие и ульты считаются по skills.csv, есть рывки, навесные снаряды, призванные существа и бомбы
уровень силы бойца влияет на здоровье и урон

Патчер ассетов

можно подменять файлы клиента (csv, sc, локализацию), клиент сам скачает изменения при входе
Как запустить

Понадобится .NET 8 SDK.

bash
git clone https://github.com/<user>/<repo>.git
cd <repo>
dotnet run --project Server

Но сначала нужно положить игровые таблицы (см. ниже). При первом запуске сам создастся Settings.json и база данных.

Игровые таблицы

Сервер читает только csv из Assets/csv_logic. Их нужно взять из своего клиента: Brawl Stars.app/res/csv_logic. Список нужных файлов:
area_effects, cards, characters, items, locations, maps, player_thumbnails, projectiles, skills, skins, tiles

Настройки :
Всё лежит в Settings.json рядом с исполняемым файлом. Самое важное:
Поле	По умолчанию	Что делает
Address, Port	0.0.0.0, 8888	где слушает игровой сервер
RC4Key		ключ шифрования протокола
playersPerMatch	6	сколько игроков в матче
matchmakingFillWithBotsSeconds	12	через сколько секунд добирать ботами
battleMaxTicks	16000	максимальная длина боя
databasePath	Database/obiad.db	где лежит база SQLite
assetsRoot	Assets	откуда читать таблицы
gamePatcher	true	включить патчер
gamePatcherPort	9999	порт, с которого раздаются патчи
gamePatcherUrl	пусто	адрес раздачи для клиента, например http://твой-ip:9999/
gamePatcherUrl обязательно заполни, если используешь патчер: с 0.0.0.0 клиент ничего не скачает.

Как работает патчер
При входе клиент присылает хеш своего res/fingerprint.json. Если он не совпадает с серверным, сервер отвечает LoginFailed с кодом 7 и отдаёт новый отпечаток вместе с адресом раздачи. Клиент докачивает только изменившиеся файлы и перезапускается уже пропатченным.
Patcher/base-fingerprint.json   отпечаток клиента как есть (из Brawl Stars.app/res)
Patcher/Content/                файлы, которые нужно подменить

Пути внутри Content повторяют клиентские: csv_logic/cards.csv, sc/ui.sc, localization/texts.csv. Если папка пустая, патчить нечего, и проверка при входе отключена.

Структура проекта
Protocol/    пакеты, RC4, транспорт
Data/        SQLite, модели, репозитории
GameLogic/   таблицы, события, награды, правила боя
Lobby/       логин, главный экран, команды, клубы, комнаты
Battle/      битовый поток, бой, матчмейкер
Patcher/     отпечаток и раздача файлов
Server/      точка входа и настройки
Assets/      csv файлы
